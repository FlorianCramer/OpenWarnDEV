# Server Anforderungen vor Entwicklungsbeginn

- [ ] **Zentrale Funktionsaussteuerung aller elemente** welche funktion vom client genutzt werden darf, dies in einer tabellen übersicht mit troggles und einen optionalen zeitraumsangabe. Wenn eine funktion dann nicht verfügbar für den client sein soll dann wird diese in dem Konfig menü vom client auf readonly gesetzt mit der benutzerdefinierten einstellung und die funktion wird auch wenn der troggle auf an ist entfernt. bis sie wieder verfügbar ist. Es sollen auch elemente deaktivierbar sein welche der client nicht einstellen kann als art systemausgrenzung.
- [ ] Dashboardansicht aller aktiv geöffneten apps und alle aktiven anzahl der letzten 7 tage bzw mit auswertungen.

Erste denkweise in [OpenWarnDE-Firebase Hosting](Openwarndev%20firebase%20server%20konzept.md) hinterlegt.
